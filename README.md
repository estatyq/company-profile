# Company Profile

Многоязычный сайт-презентация студии с защищённой админкой, портфолио и экспортом в PDF и Word.

## Возможности

- публичный сайт на английском, индонезийском, украинском, немецком и испанском;
- выбор языка при первом посещении;
- защищённая страница `/admin`;
- серверное редактирование названия, контактов и текстов;
- добавление проектов и загрузка скриншотов;
- загрузка логотипа и изменение названия бренда;
- canonical, hreflang, Open Graph, `robots.txt` и многоязычный `sitemap.xml`;
- резервные копии содержимого;
- PDF и Word из актуальных данных;
- расширяемый реестр языков с английским fallback.

Фирменный пакет XCOMBINE находится в `assets/brand/`: там хранятся векторные
логотипы, компактная версия для шапки, favicon, Apple Touch Icon и социальный
превью-образ. Генератор сайта автоматически публикует эти файлы в
`site/assets/brand/`.

## Локальный запуск

```powershell
python -m pip install -r requirements.txt
powershell -ExecutionPolicy Bypass -File .\start_admin.ps1
```

Сайт: `http://127.0.0.1:8765/`

Админка: `http://127.0.0.1:8765/admin`

При первом локальном открытии `/admin` приложение попросит создать пароль.

## Запуск в Docker

1. Создайте `.env` на основе `.env.example`.
2. Задайте длинные `ADMIN_PASSWORD` и `SECRET_KEY`.
3. Запустите:

```powershell
docker compose up -d --build
```

Контент и загруженные скриншоты хранятся в Docker volumes `profile_data` и `profile_uploads`.

## Безопасность публичного репозитория

В Git не попадают:

- `.env`;
- `data/` с паролем, контентом и резервными копиями;
- сессионный ключ;
- загруженные пользователем изображения;
- журналы;
- приватные ключи и сертификаты.

Перед публичным запуском задайте `ADMIN_PASSWORD` и `SECRET_KEY` в переменных окружения хостинга. При работе через HTTPS установите `COOKIE_SECURE=1`.

Подробная инструкция по настройке, языкам и публикации находится в [DEPLOY_GUIDE.md](DEPLOY_GUIDE.md).
